# AWS Cloud Practitioner Practice Exam 1

## Questions 1-65

### Question 1
Which AWS service provides a fully managed NoSQL database?
- A) Amazon RDS
- B) Amazon DynamoDB
- C) Amazon Redshift
- D) Amazon Aurora

**Answer: B**
**Explanation:** DynamoDB is AWS's fully managed NoSQL database service. RDS and Aurora are relational databases, and Redshift is a data warehouse.

### Question 2
What is the AWS Well-Architected Framework pillar that focuses on the ability to recover from failures?
- A) Performance Efficiency
- B) Reliability
- C) Security
- D) Cost Optimization

**Answer: B**
**Explanation:** Reliability pillar focuses on the ability to recover from failures and meet demand.

### Question 3
Which service allows you to run code without provisioning servers?
- A) Amazon EC2
- B) AWS Lambda
- C) Amazon ECS
- D) AWS Elastic Beanstalk

**Answer: B**
**Explanation:** AWS Lambda is a serverless compute service that runs code without server management.

### Question 4
What is the maximum number of S3 buckets per AWS account by default?
- A) 50
- B) 100
- C) 500
- D) Unlimited

**Answer: B**
**Explanation:** By default, you can create up to 100 S3 buckets per AWS account.

### Question 5
Which AWS service provides DDoS protection?
- A) AWS WAF
- B) AWS Shield
- C) Amazon GuardDuty
- D) AWS Firewall Manager

**Answer: B**
**Explanation:** AWS Shield provides DDoS protection. Shield Standard is free, Shield Advanced is paid.

### Question 6
What is the pricing model for AWS Lambda?
- A) Per hour
- B) Per request and compute time
- C) Monthly subscription
- D) Per GB of storage

**Answer: B**
**Explanation:** Lambda charges based on number of requests and compute time (GB-seconds).

### Question 7

- A) Amazon VPC

- D) AWS Transit Gateway

**Explanation:** Amazon VPC (Virtual Private Cloud) provides isolated virtual networks.

### Question 10
What is the AWS shared responsibility model?
- A) AWS manages everything
- B) Customer manages everything
- C) AWS manages infrastructure, customer manages data and applications
- D) Customer manages infrastructure, AWS manages data

**Answer: C**
**Explanation:** AWS manages infrastructure (hardware, facilities), customers manage data, applications, and access.
