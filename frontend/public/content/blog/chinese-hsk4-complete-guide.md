# Chinese HSK 4 - Upper-Intermediate Guide

## Overview

**HSK 4** tests upper-intermediate Chinese proficiency for discussing a wide range of topics fluently.

### Requirements
- **Vocabulary**: 1200 words (600 new)
- **Test Duration**: 105 minutes
- **Passing Score**: 180/300

## Advanced Grammar

### 1. 把 Construction (Advanced)
```
他把房间打扫得很干净。
Tā bǎ fángjiān dǎsǎo de hěn gānjìng.
He cleaned the room very clean.
```

### 2. 被 Passive (Extended)
```
这个问题被大家讨论了很久。
Zhège wèntí bèi dàjiā tǎolùnle hěn jiǔ.
This problem was discussed by everyone for a long time.
```

### 3. 使/让 Causative
```
这件事使我很感动。
Zhè jiàn shì shǐ wǒ hěn gǎndòng.
This matter moved me deeply.
```

### 4. 无论...都 (wúlùn...dōu)
```
无论多难，我都要坚持。
Wúlùn duō nán, wǒ dōu yào jiānchí.
No matter how difficult, I will persist.
```

### 5. 既...又 (jì...yòu)
```
他既聪明又努力。
Tā jì cōngming yòu nǔlì.
He is both smart and hardworking.
```

### 6. 越来越 (yuèláiyuè)
```
天气越来越冷了。
Tiānqì yuèláiyuè lěng le.
The weather is getting colder and colder.
```

### 7. 连...都/也 (lián...dōu/yě)
```
他连一句话都没说。
Tā lián yí jù huà dōu méi shuō.
He didn't say even one word.
```

### 8. 不管...都 (bùguǎn...dōu)
```
不管多忙，我都会给你打电话。
Bùguǎn duō máng, wǒ dōu huì gěi nǐ dǎ diànhuà.
No matter how busy, I will call you.
```

## Sample Dialogue

### Job Interview
```
A: 请介绍一下你自己。
   Qǐng jièshào yíxià nǐ zìjǐ.
   Please introduce yourself.

B: 我叫王明，今年25岁，毕业于北京大学。
   我有三年的工作经验，对这个职位很感兴趣。
   Wǒ jiào Wáng Míng, jīnnián 25 suì, bìyè yú Běijīng Dàxué.
   Wǒ yǒu sān nián de gōngzuò jīngyàn, duì zhège zhíwèi hěn gǎn xìngqù.

A: 你为什么想来我们公司工作？
   Nǐ wèishénme xiǎng lái wǒmen gōngsī gōngzuò?
   Why do you want to work at our company?

B: 因为贵公司在这个行业很有名，而且发展前景很好。
   Yīnwèi guì gōngsī zài zhège hángyè hěn yǒumíng, érqiě fāzhǎn qiánjǐng hěn hǎo.
```

## Practice Questions

### Reading (Sample)
```
随着科技的发展，人们的生活方式发生了很大的变化。
现在，越来越多的人选择在网上购物，因为这样既方便又省时间。
虽然网上购物有很多优点，但是也存在一些问题。
比如，有时候商品的质量不如实体店的好。
因此，我们在网上购物时要特别注意。
```

**Question**: 网上购物有什么优点？
**Answer**: 方便、省时间

### Writing Task
**Topic**: 描述你最喜欢的季节 (150-200 characters)

**Sample**:
```
我最喜欢的季节是秋天。秋天的天气不冷也不热，非常舒服。
树叶变成了黄色和红色，景色很美。这个季节还有很多水果，
比如苹果、梨等。虽然秋天很短，但是给人们带来了很多快乐。
我希望每年的秋天都能持续得更长一些。
```

## Study Strategy

### 16-Week Plan
- **Weeks 1-6**: Learn 100 new words/week
- **Weeks 7-10**: Master advanced grammar
- **Weeks 11-14**: Reading & writing practice
- **Weeks 15-16**: Full mock tests

### Key Skills
1. Read 400-600 character passages
2. Write 150-200 character essays
3. Understand complex sentence structures
4. Express opinions fluently
