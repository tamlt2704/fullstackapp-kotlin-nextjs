# fullstackapp-kotlin-nextjs

Fullstack application with Kotlin Spring Boot backend and Next.js frontend.

## How to Run

### Backend (Spring Boot)
```bash
./gradlew bootRun
```
Runs on http://localhost:8080

### Frontend (Next.js)
```bash
cd frontend
npm install
npm run dev
```
Runs on http://localhost:3000

## Features
- User registration and login
- Role-based authentication (USER, ADMIN)
- H2 in-memory database
- API proxy from frontend to backend
